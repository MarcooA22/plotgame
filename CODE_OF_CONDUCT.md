# Code of Conduct

PlotGame is a collaborative learning project.

Participants are expected to:

- treat others with respect;
- critique ideas, designs, and code rather than attacking people;
- give specific and constructive feedback;
- welcome beginners and questions asked in good faith;
- respect contributor attribution;
- avoid harassment, discrimination, threats, spam, and deliberately disruptive behavior;
- report security or moderation concerns privately when public discussion could cause harm.

Maintainers may remove content or restrict participation when behavior repeatedly damages the community or project.

The goal is not to eliminate disagreement. Strong technical and product disagreement is welcome when it is expressed constructively.
