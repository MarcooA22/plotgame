# Security

PlotGame is early-stage software.

Please do not publish a security vulnerability as a public Issue if it could expose users, private data, credentials, moderation systems, or infrastructure.

A private reporting channel should be defined before the project handles sensitive user accounts or public community publishing.

For now:

- do not commit credentials or API keys;
- do not include private data in Issues or Pull Requests;
- avoid publishing exploit details before maintainers have had a reasonable chance to review them.

A dedicated private security contact can be added before the project reaches that stage.
