# PlotGame Roadmap

This roadmap describes the current direction, not a closed specification.

Accepted work belongs in **Now / Next / Later**. Ideas that still need product discussion belong under **Open design questions**.

## Now — make the project ready to grow

- [ ] Document the current prototype and development workflow
- [ ] Establish reproducible basic checks around existing behavior
- [ ] Prepare the project for internationalization
- [ ] Support English and Spanish as the first maintained languages
- [ ] Add more built-in challenges across function families
- [ ] Decide code and asset licensing before accepting public contributions
- [ ] Make contribution paths clear for code, design, translations, bugs, and ideas

## Next — make the game replayable

- [ ] Persistent player progress
- [ ] Point / achievement system
- [ ] Cosmetic skin system
- [ ] More polished challenge browsing and filtering
- [ ] Optional progression / story path while keeping difficult challenges freely accessible
- [ ] Better feedback after failed attempts
- [ ] Accessibility improvements
- [ ] Additional translations contributed by the community

## Later — let the community create inside the game

- [ ] No-code in-game level editor
- [ ] Author Solution requirement for publication
- [ ] Solvability validation
- [ ] Automatic function-family classification for hints
- [ ] Publish levels directly to Community Challenges
- [ ] Discover / search / filter community levels
- [ ] Community reporting and moderation
- [ ] Creator profiles and level statistics
- [ ] Rating / difficulty system
- [ ] Community events or challenge collections

## Open design questions

These are deliberately open to contributor proposals.

### Difficulty

How should difficulty be represented?

Possible signals include:

- creator estimate
- completion rate
- average attempts
- perfect-completion rate
- player votes
- mathematical complexity
- execution precision

A hybrid model may be stronger than any single metric.

### Community discovery

How should new, high-quality, educational, unusual, and popular levels be surfaced without turning the game into a pure popularity contest?

### Alternative solutions

Should PlotGame recognize unusual or elegant alternative solutions? If so, how can this be done without forcing one definition of mathematical elegance?

### Story / progression

What kind of optional progression adds motivation without restricting the Geometry-Dash-like freedom to jump directly into hard challenges?

### Translation workflow

If the translation community grows, should PlotGame stay Git-based or adopt a dedicated localization platform?

### Moderation

What moderation model is lightweight enough for an early project but scalable enough for public user-created content?

## Ideas are welcome

If you have a better idea than something already listed here, propose it.

The roadmap is a direction, not a barrier to creativity.
